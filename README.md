# Hungry Hub - Restaurant Menu Page


## About the Project

Hungry Hub is a fictional restaurant. This page includes:

- A header with the restaurant name, tagline, and a navigation bar
- A banner section with a heading and short intro text
- Three menu categories (Starters, Main Course, Desserts) with 3 items each,
  styled as cards using padding, margin, and border
- An About Us section with the restaurant's story
- A footer with the address, opening hours, and copyright text

## How to View

1. Clone or download this repository
2. Open `index.html` in any web browser

No build tools or installation needed, it's a static page.
